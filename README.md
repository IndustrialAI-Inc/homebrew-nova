# Homebrew tap for Nova

```sh
brew install industrialai-inc/nova/nova
brew upgrade nova
```

`Formula/nova.rb` installs the `nova` command-line client from the release archives at <https://nova.endeavorai.com/dl>. Each release rewrites it automatically, so don't edit it by hand.

Without Homebrew:

```sh
curl -fsSL https://nova.endeavorai.com/install.sh | sh
```
